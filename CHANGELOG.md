# Changelog

All notable changes to File Color Rules are documented here. The project follows Semantic Versioning.

## [Unreleased]

## [0.1.2] - 2026-11-02

### Changed

- Update SnakeYAML Engine to 3.1.1 and Caffeine to 3.2.4.
- Update Kotlin to 2.4.20, IntelliJ Platform Gradle plugin to 2.19.0, and Gradle to 9.7.1.
- Update GitHub Actions dependencies, keeping CodeQL initialization and analysis on the same version.

## [0.1.1] - 2026-09-02

### Fixed

- Give the Project View context-action submenu its visible File Color Rules label.

## [0.1.0] - 2026-08-26

### Added

- Initial open-source IntelliJ Platform plugin.
- YAML v1 parser, validation, compilation, and canonical serialization.
- Project View file and folder background colors.
- Theme-aware palette, nested conditions, glob and RE2/J matchers.
- Bounded match cache, VFS hot reload, and last-valid fallback.
- Settings editor, path tester, and Project View context actions.
- Build, test, verification, signing, and release automation.
